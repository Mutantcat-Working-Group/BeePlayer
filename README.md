<h2>BeePlayer</h2>
</div>

### 一、产品概述

- 一个自由、开源的**媒体播放器**与**多媒体引擎**，目标是播放一切、随处运行。
- 能够读取绝大多数多媒体文件、光盘、网络串流与采集设备，并可进行转码、录制、推流等处理。
- 内置可嵌入第三方应用的引擎 **libVLC**，提供 C、C++、Python、C# 等语言绑定。
- 支持 Windows、macOS、GNU/Linux、BSD、Android、iOS 等主流平台。
- 全格式覆盖、稳定播放；同一引擎跨平台运行；所有源码可审阅、可修改。
- **发行方** 由异猫工作群（mutantcat.org）发行，GitHub: https://github.com/Mutantcat-Working-Group

核心价值：播放器能放的它都能放，引擎能嵌进你的程序里替你干活。

### 二、软件界面

- 主窗口通过「媒体」菜单打开文件、光盘、网络串流或采集设备。
- 内置播放列表、字幕加载、音视频均衡器、皮肤与可视化效果。
- 命令行与远程控制界面（HTTP / telnet CLI）适合脚本化与无人值守场景。

### 三、功能说明

#### 播放能力

- 多媒体文件、光盘、网络串流、采集设备全支持。
- 转码、录制、推流一站式完成。
- 插件化编解码与访问架构，`modules/` 下有编解码器、封装、音视频输出等模块。

#### libVLC 嵌入式引擎

- 引擎与应用分离，允许外部应用保持自己的许可证。
- 桌面、移动端、Web 控制台均有 GUI 实现。

#### 开发进度

- [X] 多媒体文件播放

- [X] 跨平台 GUI（桌面、移动端、Web 控制台）
- [X] libVLC 嵌入式引擎
- [X] 插件化编解码与访问架构

### 四、安装与下载

1. 桌面与移动端使用：在 Windows、macOS、GNU/Linux、BSD、Android、iOS 等平台上安装对应发行包即可使用，各平台安装包见本仓库 [Releases](https://github.com/Mutantcat-Working-Group/BeePlayer/releases) 页面。
2. 开发者集成：在自己应用中引入 libVLC（见第六章），即可获得播放、转码和串流能力，无需重写底层。
3. 自行编译：按第七章准备工具链后从源码构建。

### 五、快速上手

1. 打开 BeePlayer，通过「媒体」菜单打开文件、光盘、网络串流或采集设备。
2. 使用内置播放列表、字幕、音视频均衡器、皮肤与可视化等功能。
3. 命令行方式：`vlc [选项] <文件或流地址>`。
4. 远程控制可启用 HTTP 界面或 telnet CLI 界面。

### 六、接口说明

#### libVLC 公共 API

- C 头文件位于 `include/vlc`。
- 引擎源码位于 `lib/` 与 `src/`。

#### 语言绑定

- C、C++、Python、C# 等绑定位于 `bindings/`。

#### 插件与模块

- `modules/` 包含编解码器、封装、音频/视频输出、访问模块等插件体系。

### 七、从源码构建

- 各平台的编译步骤、依赖与配置项见 [INSTALL](INSTALL) 文件。
- 需要自行编译时，请按该文件准备对应平台的工具链后再执行构建。

### 八、开源协议

- BeePlayer 本体采用 GPLv2（或更新版本）授权。
- libVLC 引擎采用 LGPLv2（或更新版本）授权，可嵌入第三方应用。
